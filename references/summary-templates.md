# MODE-B 归纳总结标准模板

> 本模板用于 MODE-B(归纳总结)。每篇文献输出一份独立 `.md`,文件名 = 论文 slug + `.md`(全小写、空格/特殊字符替换为 `-`)。
> 批量(≥3 篇)时另出一份 `00-OVERVIEW.md`(主题分类 + 一句话速览表 + 文件索引)。

---

## 单篇模板

```markdown
# 论文总结 / Paper Summary

## 1. 基本信息表

| 字段 | 内容 |
|---|---|
| **标题** | (中文译名 / English Title) |
| **作者** | First Author, Second Author, ...(全列;若 >6 人写 "et al.") |
| **机构** | (主要单位) |
| **发表年份** | YYYY |
| **发表于** | (会议/期刊全名 + 缩写,如 "CVPR 2024"、"IEEE TITS") |
| **DOI / arXiv** | (完整链接) |
| **任务领域** | (如:图像分类 / 端到端检测 / 大模型微调,按论文实际领域填写) |
| **数据集** | (主要数据集名称,逗号分隔) |
| **硬件 / 算力** | (训练硬件配置,如有) |

---

## 2. 一句话摘要(TL;DR)

> [≤ 50 字,中文。必须包含「做了什么 + 用了什么方法 + 达到什么效果」。禁止"颠覆性""革命性"等空话。]

---

## 3. 研究背景与动机

[3~6 段中文叙述。说明:本研究解决什么问题 / 为什么这个问题重要 / 现有方法的不足 / 本文从何角度切入。
**保留具体数字**:事故数、年份、数据集规模、基线模型精度等一律照搬。]

---

## 4. 核心贡献

1. **[贡献 1 一句话标题]**:[2~4 句详细说明,带数据]
2. **[贡献 2 一句话标题]**:...
3. **[贡献 3 一句话标题]**:...

(贡献条目数与原文一致,通常 3~5 条)

---

## 5. 方法论

### 5.1 总体框架

[整体架构、输入输出、关键模块的串联关系。可附 mermaid 流程图或文字描述。]

### 5.2 关键技术细节

- **[模块 1 名称]**:输入 / 输出 / 关键操作 / 与基线的差异
- **[模块 2 名称]**:...
- **[损失函数 / 训练策略]**:具体公式或伪代码
- **[超参数]**:学习率、batch、epoch 等(如原文给出)

---

## 6. 实验结果

### 6.1 数据集

| 数据集 | 规模 | 用途 |
|---|---|---|
| ... | ... | 训练 / 验证 / 测试 |

### 6.2 主要结果

| 方法 | 指标 1 | 指标 2 | ... |
|---|---|---|---|
| Baseline A | ... | ... | |
| **本文方法** | **...** | **...** | |

(保留所有具体数值,不要"显著提升"代替数字)

### 6.3 消融实验

[若有消融,逐项列出每个组件的贡献。]

---

## 7. 局限性

- [局限 1,带原文出处]
- [局限 2]
- [作者自述的未来工作]

---

## 8. 个人点评(Critical Assessment)

**优点**:[亮点 / 创新性 / 可借鉴之处,3~5 条]

**不足**:[潜在问题 / 未验证假设 / 数据集偏倚 / 复现门槛,3~5 条]

**对本项目的启示**:[结合用户当前研究方向给出的针对性建议]

---

## 9. 关键词

`关键词1` `关键词2` `Keyword3` ...(5~10 个,中英混排)

---

## 10. 相关工作

[原文 Related Work 节的中文复述,按子主题分小节。每个子主题 1~3 段。保留所有被引论文的标题 + 第一作者 + 年份。]
```

## 00-OVERVIEW.md 模板(批量场景)

```markdown
# 文献综述索引

> 共 N 篇文献,涵盖 X 个主题方向。

## 一、按主题分类

### 主题 A:[主题名]
- [#1] [论文标题] → [`xxx.md`](xxx.md)
- [#3] [论文标题] → [`yyy.md`](yyy.md)

### 主题 B:[主题名]
- [#2] [论文标题] → [`zzz.md`](zzz.md)

## 二、一句话速览表

| # | 标题(简称) | 任务 | 数据集 | 核心方法 | 关键结果 |
|---|---|---|---|---|---|
| 1 | [论文简称] | [任务] | [数据集] | [核心方法] | [关键结果] |
| 2 | ... | ... | ... | ... | ... |

## 三、阅读建议顺序

1. 入门:[#X], [#Y](方法清晰、范围窄)
2. 进阶:[#A], [#B](涉及多模态融合)
3. 前沿:[#M], [#N](2024 年最新工作)
```

## 关键原则(重复一遍,因为最容易违反)

| ❌ 不要这样 | ✅ 应该这样 |
|---|---|
| "在多个数据集上验证" | "在 ImageNet、CIFAR-100、COCO 三个数据集上验证"(写出全部具体名字) |
| "显著提升精度" | "Top-1 准确率从 89.2% 提升至 94.7%(+5.5 pp)"(保留原文数字) |
| "采用先进的注意力机制" | "采用 channel-spatial dual attention,参考 CBAM[Woo et al., 2018]"(写出具体技术与出处) |
| "训练成本可控" | "8×A100 训练 12 小时"(写出硬件 + 时长) |
| "方法效果良好" | (删除这种空话) |
